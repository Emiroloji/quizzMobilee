# ADR 0011 — UUIDv7 kimlikler

- **Tarih:** 2026-10-28
- **Durum:** Kabul

## Bağlam
Kimlikler uygulamada üretilmeli (olay yayını transaction içinde ID gerektirir), modüller ve servisler arasında çakışmamalı, indeks dostu olmalı.

## Karar
Tüm birincil anahtarlar uygulamada üretilen **UUIDv7**'dir. Kotlin'de `@JvmInline value class` (`UserId`, `QuestionId`…) ile tiplenir; ham `UUID` modül sınırından geçmez.

## Alternatifler
- **bigserial:** Veritabanına bağımlı, servise ayırmada çakışır.
- **UUIDv4:** Rastgele; B-tree indekslerinde parçalanma.

## Sonuçlar
- (+) Zamana göre sıralı, indeks dostu, dağıtık üretilebilir.
- (−) ID'den oluşturma zamanı çıkarılabilir (hassas değil).
